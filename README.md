# nocosheet.github.io

Landing page for [nocosheet](https://github.com/nocosheet/nocosheet), built with Astro and deployed to GitHub Pages.

## Develop

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

Pushing to `main` deploys through `.github/workflows/deploy.yml`. Set Pages source to GitHub Actions in the repository settings.
